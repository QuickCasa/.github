# Getting help

Here's where to go for help with QuickCasa's open source projects.

- **A question or bug in one of our projects:** open an issue in that project's
  repository. For a bug, include the version you're using and the steps to
  reproduce it.
- **A security problem:** don't open an issue. Follow the
  [security policy](https://github.com/QuickCasa/.github/blob/main/SECURITY.md).
- **The QuickCasa product:** these repositories aren't a support channel for
  QuickCasa itself. Email [support@quickcasa.ai](mailto:support@quickcasa.ai).
- **Anything else:** email [hello@quickcasa.ai](mailto:hello@quickcasa.ai).
